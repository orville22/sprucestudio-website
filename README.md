# Spruce Studio website

Static site for [sprucestudio.com.au](https://sprucestudio.com.au).

- `index.html` — homepage
- `privacy.html` — privacy page

No build step. Deploy on Vercel with the "Other" framework preset and the project root as the output directory.

## Before launch
- Replace `YOUR_FORM_ID` in `index.html` with your Formspree form ID
- Replace `[TURNAROUND]` in `index.html`
